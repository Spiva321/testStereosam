# ОфисСклад — «Увеличить прибыль магазина»

Три задачи кейса закрыты тремя файлами.

## `officesklad_dashboard.html` — задача 1 «Данные»

HTML-дашборд по выгрузке Яндекс.Метрики (22 июля — 20 октября 2026): KPI, графики трафика, источники, устройства, поисковые запросы, аномалии и качество измерений. В конце — выводы и предложения по изменениям на сайте.

## `officesklad_UI.html` — задача 2 «UI/UX»

Свёрстанный прототип новой главной страницы магазина: усиленный поиск, фильтры, карточки товаров с наличием и оптовыми ценами, корзина. Адаптирован под мобильные. Открывается в браузере.

## `recommendations_officesklad.md` — задача 3 «Рекомендации»

Текстовые рекомендации: что улучшить на сайте и почему это должно увеличить прибыль.

## Запуск

```bash
open officesklad_dashboard.html
open officesklad_UI.html
```
